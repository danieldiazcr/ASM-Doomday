# Generador de Calendarios en Ensamblador

Proyecto desarrollado en ensamblador x86 que permite generar
calendarios mensuales o anuales utilizando cálculos de día de la semana
basados en algoritmos tipo Doomsday/Sakamoto.

## Características

- Ensamblador x86
- Compatible con DOSBox
- Soporte para calendario Juliano y Gregoriano
- Cálculo de años bisiestos
- Impresión de meses individuales o año completo
- Soporte para años A.C.
- Manejo especial de la transición de octubre de 1582

## Tecnologías utilizadas

- x86 Assembly
- TASM
- DOSBox
